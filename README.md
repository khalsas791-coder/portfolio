# Sardar Jaspreet Singh Kapse — Personal Portfolio

A sleek, responsive personal portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

![Portfolio Preview](./src/assets/hero.png)

---

## 🚀 Features

- **Dynamic Interactive UI**: Built with Tailwind CSS and Framer Motion for smooth animations and transitions.
- **Modern Dark Cyberpunk Aesthetic**: High-res backdrop, glowing accents, and glassmorphism cards.
- **Hero Section**: Typist animation rotating through engineering specializations, quick links, and recruiter snapshots.
- **Projects Showcase**: Interactive project cards highlighting AI/ML, Computer Vision, and Full-Stack web apps with live preview and repo links.
- **Functional Contact Form**: Direct message delivery powered by [Web3Forms](https://web3forms.com/) via `fetch` API.
- **Fully Responsive**: Optimized for desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## ⚡ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/khalsas791-coder/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Set up environment variables
Create a `.env` file in the root directory:
```bash
cp .env.example .env
```
Add your free Web3Forms access key from [web3forms.com](https://web3forms.com):
```env
VITE_WEB3FORMS_ACCESS_KEY=your_access_key_here
```

### 4. Run the development server
```bash
npm run dev
```
